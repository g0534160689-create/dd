# דעת אהרן — המרכז הדיגיטלי ל-Windows

יישום Windows בעברית, RTL, המאגד את פורטל השירותים, טעינת רב־קו, דפדפן פנימי וכלי ניהול מדיניות בממשק אחד.

## טכנולוגיות
- C# / .NET 10
- WPF + XAML (ממשק Windows)
- Microsoft Edge WebView2 (דפדפן מוטמע)
- Windows x64
- שמירת מדיניות מקומית ב-JSON עם גיבוי; אין העלאת הגדרות או סיסמת מנהל ל-GitHub

## יכולות שנבנו בגרסה הנוכחית
- פורטל פנימי עם שירותי הישיבה: נדרים פלוס, תורה דיליה, הטענת הדפסות, מבחני דרשו, ישיבה על קברו, מבחני לדעת, שיח התורה, תורה שבכתב, HopOn ורב־קו אונליין.
- פתיחת השירותים בתוך חלון WebView2 של התוכנה.
- כללי ניווט HTTPS, רשימת דומיינים מורשים, חסימת נתיבים מוגדרים ב-HopOn, והגבלת רב־קו אונליין לנתיב החיבור.
- אזור ניהול מוסתר שנפתח באמצעות Ctrl+Shift+A ומוגן בסיסמה מקומית. בהפעלה הראשונה מגדירים סיסמה פעמיים; שינוי סיסמה דורש אימות הסיסמה הקודמת.
- הוספת כללי חסימה והרשאה לפי דומיין ונתיב, שמירה מקומית וייצוא/ייבוא גיבוי.
- בחירת רכיב בעמוד בלחיצה ימנית ושמירת כלל חסימה; ניתן לבחור רכיב חסום ולהחזירו.
- שליטה בהרשאת חלונות קופצים מאותו דומיין מאושר.
- חסימת ניווט לדומייני Google Pay מוכרים והסרה של רכיבי Google Pay גלויים בעמוד, ככל שהאתר מאפשר גישה אליהם.
- מעבר חד-פעמי של כללי הניהול מהתיקיות של הגרסה הישנה, כאשר קובץ ההגדרות הישן קיים.
- רישום תקלות ופעילות תחת `%LOCALAPPDATA%\\DaatAharon`.

## אבטחה ומגבלות שחשוב להכיר
- רב־קו אונליין מוגבל לנתיב `/he/store/connect`; HopOn משתמש ברשימת נתיבים חסומים.
- חלונות קופצים מאושרים כרגע רק כאשר הם מאותו דומיין של הדף הפעיל וגם הדומיין מורשה.
- חסימת רכיבי Google Pay בדף תלויה במבנה ה-HTML של ספק התשלום; אין אפשרות להבטיח חסימה של רכיב שמוצג בתוך iframe חוצה-דומיינים או חלון תשלום חיצוני.
- התוכנה אינה שומרת פרטי אשראי ואינה מבצעת חיובים בעצמה.
- בדיקת Build אוטומטית אינה תחליף לבדיקה פיזית עם קורא USB וכרטיס רב־קו אמיתי. אין להציג את קורא הכרטיסים כמאומת עד לבדיקה כזו.

## בנייה מקומית
דרישות: Windows 10/11 x64 ו-.NET 10 SDK.

```powershell
dotnet restore DaatAharon.sln
dotnet build DaatAharon.sln -c Release
dotnet publish src/DaatAharon.Desktop/DaatAharon.Desktop.csproj -c Release -r win-x64 --self-contained true
```

## פרסום
GitHub Actions בונה את היישום, יוצר מתקין Windows וגרסה ניידת ZIP, ומעלה אותם ל-GitHub Releases רק לאחר שלבי הבנייה.
